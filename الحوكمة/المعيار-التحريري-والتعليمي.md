# المعيار التحريري والتعليمي للأكاديمية العقارية السعودية

**الحالة:** معيار حاكم لإعداد المحتوى ومراجعته ونشره.

## 1. الهوية التحريرية
- العربية الفصحى الواضحة هي لغة المحتوى الأساسية.
- تُستخدم المصطلحات العقارية والمحاسبية والنظامية بدقة، ويُذكر المقابل الإنجليزي عند الحاجة.
- تعتمد الكتابة الموضوعية المباشرة والعناوين الوصفية والفقرات المترابطة.
- يُخاطب المتعلم بصفته دارساً في برنامج مهني، لا طرفاً في محادثة شخصية.
- تُحذف المقدمات الإنشائية والتكرار والتحفيز غير المرتبط بناتج تعلم.

## 2. أساليب غير مقبولة
يُمنع تضمين آثار المحادثة وتعليمات المساعد، ومنها: «سأقدم لك»، «دعنا نبدأ»، «تخيل أنك» بوصفها افتتاحية حوارية، «أريد منك»، «هل أنت مستعد؟»، «أخبرني عندما تنتهي»، «يمكنك أن تسألني»، «سأشرح لك»، «ما رأيك؟»، «أرسل إجابتك للتصحيح»، أو أي صياغة تجعل المادة تبدو رداً مولداً أثناء محادثة. تُستبدل بصيغ وظيفية مثل «حالة تطبيقية»، «المهمة العملية»، «متطلبات التنفيذ»، «أسئلة مراجعة ذاتية»، و«معيار قبول المخرج».

## 3. بنية الدروس
تُختار عناصر الدرس بحسب طبيعته: عنوان محدد، نواتج تعلم قابلة للقياس، مفاهيم أساسية، شرح متدرج، إجراءات عملية، أمثلة سعودية موثقة أو موسومة افتراضياً، جداول ومعادلات مفسرة، حالة تطبيقية عند الحاجة، مخرج ومعيار قبول، ومراجع قابلة للتحقق. لا يُفرض قالب آلي واحد على جميع الدروس.

## 4. الحالات والمشاريع
- يحدد كل مشروع الغرض والنطاق والمدخلات والخطوات والمخرج ومعيار القبول.
- تُصنف البيانات إلى موثقة أو افتراضية أو افتراضات أو تقديرات.
- لا تُنسب أرقام تدريبية إلى السوق أو جهة رسمية.
- تُذكر القيود ومخاطر القرار ونقاط عدم اليقين.

## 5. التعليمات والمخرجات
- تبدأ التعليمات بفعل تنفيذي واضح مثل إعداد أو حصر أو تحليل أو مقارنة أو توثيق.
- تحدد صيغة التسليم ومكوناته ومستوى التفصيل.
- لا يُطلب إرسال الإجابات إلى مساعد ذكاء اصطناعي أو انتظار تصحيحه.
- يوضح معيار القبول شروط اكتمال المخرج.

## 6. المصادر والدقة النظامية
- تُستخدم المصادر الرسمية المباشرة للأنظمة واللوائح والتراخيص والرسوم.
- يذكر اسم الجهة والوثيقة أو الصفحة وتاريخ الاطلاع ورابط مباشر.
- تُوسم المعلومات: [نظامي]، [ممارسة مهنية]، [تقدير]، [توضيحي].
- لا تُعرض الممارسة المهنية بوصفها التزاماً نظامياً.
- لا يُختلق رقم أو شرط نظامي عند غياب مصدر موثوق؛ يوثق موضع النقص بوصفه بحاجة إلى تحقق.
- لا يُعرض التحليل الاسترشادي بصفته تقييماً معتمداً أو استشارة قانونية أو ضريبية.

## 7. الاختبارات والتقييم
- تعتمد الأكاديمية الدراسة الكاملة للمراحل التسع دون اختبارات مرحلية تقييمية أثناء الدراسة.
- أسئلة المراجعة الذاتية اختيارية وتكوينية ولا تدخل في الدرجة الرسمية.
- لا تُطلب إجابات المتعلم عبر محادثة مع مساعد آلي.
- يُتاح بنك الاختبارات بعد إتمام دراسة المنهج.
- يُحدد المستوى النهائي من نتائج الاختبارات النهائية والمخرجات العملية وفق معايير معلنة.
- لا يُنشأ وضع بديل أو بوابة اختبار مرحلية دون قرار موثق من مالك البرنامج.

## 8. جودة المحتوى والواجهة
- تُراجع المصطلحات والتعريفات والحسابات ووحدات القياس واتساق الأمثلة.
- تُراجع الروابط والمراجع دورياً، خصوصاً المعلومات النظامية والسوقية.
- تُفصل المادة التعليمية عن رسائل الإدارة والتطوير وملاحظات الوكلاء والموجهات الداخلية.
- لا تظهر للمتعلم أسماء الفروع أو الالتزامات البرمجية أو تعليمات فريق التطوير.
- تُحافظ التحديثات على مفاتيح التخزين المحلي وآلية حفظ التقدم.

## 9. قائمة تحقق قبل النشر
- [ ] العنوان يصف موضوعاً تعليمياً محدداً.
- [ ] لا توجد مخاطبة حوارية أو آثار محادثة أو تعليمات مساعد.
- [ ] نواتج التعلم قابلة للملاحظة أو القياس.
- [ ] الشرح كافٍ ولا يحذف معرفة لازمة.
- [ ] الأمثلة والأرقام والعمليات الحسابية متسقة.
- [ ] البيانات والافتراضات والتقديرات موسومة.
- [ ] المعلومات النظامية مستندة إلى مصادر رسمية حديثة.
- [ ] التمرين يحدد مخرجاً ومعيار قبول.
- [ ] لا توجد اختبارات مرحلية تقييمية أو طلبات إرسال إجابات لمساعد.
- [ ] السياسة متسقة مع دليل الدراسة ومنظومة التقييم.
- [ ] الروابط والجداول والعرض على الهاتف سليمة.
- [ ] لا تظهر تعليمات داخلية أو بيانات إدارية غير موجهة للمتعلم.
