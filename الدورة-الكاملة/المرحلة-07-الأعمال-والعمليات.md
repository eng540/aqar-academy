# المرحلة 7 — إدارة الأعمال والعمليات العقارية (النص الكامل للدراسة)

**مخرجات المرحلة:** أن تعمل داخل شركة عقارية بفهم كامل لأقسامها، وأن تبني منظومة قابلة للتوسع: هيكل، إجراءات SOP، مؤشرات KPI، تقارير، ونظام فرص مركزي.

---

## المحور 1: تشريح شركة عقارية

### الأقسام النموذجية لشركة تطوير
| القسم | وظيفته | مؤشر نجاحه الأساسي |
|---|---|---|
| التطوير | اكتشاف الفرص ودراستها وإطلاقها | عدد الفرص المؤهلة / جودة الهوامش |
| المبيعات والتسويق | تحويل المنتج إلى مبيعات | سرعة البيع / التحويل |
| إدارة المشاريع (PMO) | تنفيذ على زمن/تكلفة/جودة | التجاوزات والتأخير |
| المالية | السيولة، التحصيل، الميزانية | توفر السيولة في نقاط الضعف |
| العمليات/إدارة الأملاك | تشغيل وتحصيل وصيانة | نسبة الشغور/التحصيل |
| القانونية/الالتزام | العقود والامتثال | خلو من النزاعات |

### تدفق العمل من الفرصة إلى التسليم
`فرصة ← فحص أولي ← دراسة جدوى ← موافقة إدارة ← أرض وعقود ← تصميم وتراخيص ← تنفيذ ← تسويق وبيع ← تسليم ونقل ← تشغيل/متابعة`

## المحور 2: إدارة المبيعات والتسويق

### القمع البيعي بالأرقام `[توضيحي]`
100 استفسار ← 60 مؤهل ← 25 معاينة ← 8 عروض ← 3 صفقات. **مؤشر جودة التسعير:** نسبة المعاينة→عرض؛ **مؤشر جودة الاستهداف:** استفسار→مؤهل.

### الأهداف والعمولات
هدف شهري لكل بائع (عدد صفقات + قيمة)، عمولة تصاعدية (عتبات)، مكافأة سرعة إغلاق. **القاعدة:** لا عمولة تُصرف قبل التحصيل الفعلي من العميل.

### تقارير أسبوعية (قالب)
مخزون جديد، صفقات مغلقة، معاينات، عروض قائمة، عمولات مستحقة، أخطر صفقة معلقة ولماذا.

## المحور 3: إدارة التطوير والمشاريع (PMO وبوابات القرار)

### البوابات الخمس
1. **بوابة الفكرة:** فرصة جابت الفلتر السباعي؟
2. **بوابة الجدوى:** دراسة مكتملة وسيناريو متحفظ يصمد؟
3. **بوابة الموافقة:** ميزانية معتمدة ومصادر تمويل واضحة؟
4. **بوابة التنفيذ:** تجاوزات ضمن حدود؟ دفعات مقابلة لإنجاز؟
5. **بوابة التسليم:** جودة مقبولة، أوراق مكتملة، بيع/تسليم مُغلق.

**القاعدة:** لا مشروع يعبر بوابة بقرار شفهي — وثيقة قصيرة (صفحة) لكل بوابة: القرار، الأرقام، المخاطر، المتنازل عنه.

## المحور 4: الإجراءات التشغيلية SOP

### منهجية كتابة إجراء (5 أجزاء)
1. **الهدف** — لماذا الإجراء؟
2. **المسؤول** — من يملكه ومن ينفذ خطواته؟
3. **الخطوات** — مرقمة، واضحة، بلا اجتهادات.
4. **النماذج** — قوالب الأوراق المستخدمة.
5. **المؤشر** — كيف نقيس جودة تنفيذه؟

### خمسة إجراءات تؤسس أي شركة عقارية صغيرة
1. استقبال الفرصة وتصنيفها (نموذج فحص أولي).
2. فحص نظامي لعقار قبل أي اتفاق (قائمة المرحلة 2).
3. إعداد عرض عقاري ومعتمده (تصوير/تسعير/نشر).
4. عقد بيع/إيجار (نماذج موحدة + تدقيق قبل التوقيع).
5. متابعة تحصيل وتقارير دورية (جدول أسبوعي ثابت).

**مبدأ التوسع:** كل عمل متكرر يجب أن يتحول من «خبرة شخص» إلى «إجراء مكتوب + نموذج + مؤشر» — هذا الفرق بين عمل فرد ومنظومة قابلة للنمو.

## المحور 5: مؤشرات الأداء KPI والتقارير

### لوحة أسبوعية مصغرة (نموذج)
| القسم | المؤشر | الهدف `[توضيحي]` |
|---|---|---|
| التطوير | فرص جديدة مفحوصة / نسبة تمرير | 5 / 20% |
| المبيعات | صفقات مغلقة / متوسط زمن الإغلاق | 3 / ≤45 يوم |
| المشاريع | تجاوز تكلفة / تأخير | ≤5% / ≤15 يوم |
| المالية | تحصيل الشهر / سيولة متاحة | 100% / 3 أشهر مصاريف |
| العمليات | شغور / تحصيل إيجارات | ≤8% / ≥95% |

### قواعد مؤشرات جيدة
قابلة للقياس أسبوعياً؛ صاحب مسؤول واحد؛ هدف رقمي؛ تنبيه عند الانحراف. **أقل من 10 مؤشرات على اللوحة الرئيسة** — كثرتها تقتل الانضباط.

## المحور 6: نظام الفرص المركزي وقابلية التوسع

### نظام إدارة الفرص (Opportunity Pipeline)
`مكتشف ← مفحوص (فلتر) ← قيد دراسة ← جدوى مكتملة ← موافق/مرفوض ← تحت التنفيذ ← مغلق (ناجح/خاسر مع الدروس)`
كل فرصة ملف: مصدرها، أرقامها، قراراتها، ودرسها — حتى المرفوضة (مكتبة قرارات تحميك من تكرار الأخطاء).

### من فرد إلى منظومة (مسار التوسع)
1. فرد ينفذ كل شيء (0–1 مشروع).
2. فرد + إجراءات مكتوبة (قابلية تعليم آخر).
3. فريق صغير بأدوار محددة ولوحة KPI.
4. نظام يُدار بالتقارير لا بالحضور.

## تمارين المرحلة
1. ارسم هيكل شركة تطوير صغيرة (5 أقسام) واكتب تدفق الفرصة عبرها.
2. اكتب SOP كاملاً (5 أجزاء) لـ«استقبال الفرصة».
3. صمّم لوحة KPI أسبوعية (8 مؤشرات) لأعمالك المستقبلية.
4. اكتب تقرير أسبوع (نموذجي) لقسم مبيعات فيه 3 صفقات و5 معلقات.
5. ابنِ خط الأنابيب السبعي في ملف Excel وأدخل 5 فرص افتراضية.
6. اكتب وثيقة بوابة الجدوى (صفحة) لمشروع المرحلة 5.

## أسئلة مراجعة ذاتية
ما الأقسام الستة ووظيفة كل منها؟ ما البوابات الخمس؟ ما أجزاء SOP الخمسة؟ ما خصائص مؤشر جيد؟ ما خطوط أنابيب الفرص وكيف تُدار المرفوضة؟ ما مسار التوسع من فرد إلى منظومة؟
