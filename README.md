### 2. المشاريع والحالات التطبيقية

- حالات تدريبية ومحاكاة لاتخاذ القرار وتحليل الفرص.
- تطبيقات مرتبطة بالسوق السعودي ومكة المكرمة.

### 3. الأدوات وقوالب العمل
- سجلات لتنظيم العقارات والعملاء والفرص.
- نماذج للتحليل المالي ودراسة الجدوى.
- أدوات مساعدة لجمع البيانات وتنظيمها وتحليلها.

### 4. البحث وتنظيم المعرفة
- مراجع للجهات والمنصات الرسمية.
- توثيق للمصادر والتواريخ والافتراضات.
- فصل بين المتطلبات النظامية والممارسات المهنية والتقديرات والأمثلة التوضيحية.

- للمبتدئ الذي يريد أن يعرف من أين يبدأ في السوق العقاري السعودي.

- للممارس الذي يريد تنظيم معرفته وتطوير أدواته وآليات عمله.
- للباحث عن فرص التطوير العقاري أو الاستثمار أو تأسيس نشاط مرتبط بالقطاع.
- للجهات والمهنيين المهتمين بنماذج إعداد المحتوى وتنظيم المعرفة وتطوير الأدوات والمشاريع.

## منهجية المعرفة والتطبيق

يقوم المشروع على مبدأ: **افهم السوق، تعلّم أدواته، طبّق، ثم وثّق ما أنجزته.**

وتُميّز المواد بين:
- **[نظامي]:** معلومة أو متطلب تنظيمي ينبغي التحقق منه في مصدر رسمي.
- **[تقدير]:** تحليل أو رقم تقريبي يتطلب بيانات سوقية مناسبة.
- **[توضيحي]:** بيانات افتراضية لأغراض الشرح والتدريب.
