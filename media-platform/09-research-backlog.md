# 09 — سجل البحث والقرارات المفتوحة

## 1. الحالة التنفيذية

| المسار | الحالة | ما يلزم قبل الإغلاق |
|---|---|---|
| إنشاء مساحة المشروع | منجز | مراجعة الروابط بعد النشر |
| ميثاق المشروع | مسودة أولى | مراجعة المؤسس |
| المسح المكتبي للسوق | موسع أولياً | إضافة ناشرين متخصصين وصناع محتوى وشركات تنفيذ ومنصات بيانات؛ يلزم رصد عينة منشورات موحدة |
| شرائح الجمهور | فرضيات + أداة مقابلات جاهزة | إجراء 20 مقابلة حقيقية قبل تثبيت الشريحة |
| التموضع | 3 فرضيات | اختبارها مع الجمهور |
| الاسم والهوية | مؤجل | نتائج البحث والاختبار |
| النظام التحريري | إطار + تقويم تجريبي | إنتاج ونشر 8–10 مواد بعد مراجعتها فنياً |
| منظومة القنوات | مقترح | اختبار قنوات البداية |
| خطة 90 يوماً | مسودة | اعتماد بعد البحث الميداني |
| الامتثال | إطار احترازي | مراجعة قانونية/تنظيمية قبل أي نشاط منظم |

## 2. أسئلة يجب أن تُحسم بالأدلة

1. هل الجمهور الأكثر احتياجاً هو مالك المشروع أم المقاول أم المهندس أم مزيج محدد؟
2. هل يفضّل الجمهور محتوى «قرار البناء» أم «تحليل المشاريع والفرص»؟
3. ما الأسئلة التي تتكرر فعلياً في مكة وجدة وبقية السعودية؟
4. ما الفجوات التي لا تغطيها الجهات الحالية؟
5. ما الصيغة التي تحقق قيمة حقيقية: فيديو، تقرير، ملف، مقابلة، أم أداة؟
6. هل اسم العلامة يجب أن يكون مستقلاً عن اسم المؤسس؟
7. ما القنوات التي يمكن تشغيلها بجودة مستدامة؟
8. ما المنتجات أو الخدمات التي يمكن تقديمها دون تجاوز حدود الترخيص؟

## 5. قائمة المهام التالية

- [ ] استكمال قائمة 15–20 جهة منافسة/مجاورة.
- [ ] جمع عينة 20 منشوراً حديثاً لكل جهة رئيسية مختارة.
- [ ] تحليل شكل المحتوى والتفاعل الظاهر والتوثيق.
- [ ] إجراء 20 مقابلة جمهور.
- [ ] تسجيل 30 سؤالاً أو مشكلة متكررة من الجمهور.
- [ ] اختبار 3 اتجاهات تموضع.
- [ ] إنتاج 6 نماذج محتوى واختبارها.
- [ ] إعداد تقرير قرار نهائي للهوية والجمهور.
- [ ] بعد اعتماد الهوية: تطوير نظام التصميم والقوالب.
- [ ] إطلاق تجربة نشر محدودة وقياسها.
